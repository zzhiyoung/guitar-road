# 更新记录

## 2026-10-03：曲库整理、整曲播放与练习体验

本次将专辑管理、整曲播放器和后续七项体验整改合并到 main；Creator 作为可选的实验测试功能一并提供。

### 曲库与导入

- 新增专辑的新建、重命名、排序和删除，以及曲目的专辑归类。曲库先展示专辑，再进入曲目列表；未分类与全部曲目始终可达。删除专辑保留曲目，专辑与教材来源互相独立。
- 有 GP / MusicXML 的曲目可直接整曲播放，无需创建练习段落，普通播放不产生练习任务或记录。
- 曲目列表支持“整曲加入今日练习”，复用整曲段落并按同日去重。整曲练习覆盖最新可播放文件的全部小节；不同文件格式按上传时间选择最新版本。
- 导入时默认使用谱面标题、作者；人工填写优先。创建段落时默认填入谱面 BPM 和小节数，保留手动修改。

### 专注练习

- 练习计时可暂停和继续；页面不可见、离开页面与休眠长间隔不全部计入。当前标签页保留计时草稿，记录前可核对有效分钟数。暂停计时与暂停音乐分别控制。
- 修复节选播放越过最后一小节的问题。节选完整结束后停止或在选定范围循环；弱起、拍号与提速循环采用实际音乐时间边界。普通整曲播放保留原谱反复，练习段落按书面顺序循环。
- 新增可选“预备一小节”，按起播小节拍号和速度安排预备拍，默认关闭，可取消；暂停后继续和循环不重复预备。
- 乐谱主音量默认 150%，可调范围 0–300%；保留原谱轨道音量与力度。真实扬声器、耳机及触屏体验仍需用户核对。

### Creator：仅供实验测试

**Creator 尚未达到正式自动识谱功能的验收条件，不保证准确性。** 它依赖用户自行安装的 Python / homr；不安装时核心练习功能正常使用。

- 测试图片 / 粘贴截图转换为 MusicXML 草稿，以及谱表切换、试听、暂停、停止和下载。
- 支持自动、仅五线谱和实验性五线谱＋TAB模式。组合谱尝试用五线谱时值和 TAB 弦号/品位生成单吉他声部，并展示音高冲突；对齐不可靠时拒绝合并。
- 目前仅支持有限的清晰单音组合谱，标准 EADGBE、无变调夹；纯 TAB、和弦、复杂奏法、整本教材和 PDF 自动识谱不在支持范围。
- 输出只是草稿，必须人工核对音高、节奏、弦号和品位，再用 Guitar Pro 校正。有限样本和原创 fixture 的通过结果不能视为泛化准确率。
- Creator 不自动建立歌曲或练习记录。图片在本机服务的临时目录处理，结束后清理；识别稿通过 HTTP 附件导出，再由用户手动导入曲库。

详细的测试结果与未完成验收见 [Creator 进展](CREATOR_OMR_PROGRESS.md)；安装方法见 [OMR 工具说明](../tools/omr/README.md)。

### 数据与运行

首次访问时执行增量迁移：新增专辑与曲目归属、整曲练习标记及唯一索引，旧段落默认保持节选类型。更新前应停止服务并备份整个 `data/`，其中包含数据库和上传乐谱。

更新源码后，Windows 日常版本执行 `launch-guitar-practice.bat rebuild`；手动运行使用 `npm run build` 和 `npm run start`。Node 22+、端口 3000 和默认 `.next` 构建目录不变。
